# 1. Installation and Setup

This guide provides instructions for building and installing the `hyde-ipc` CLI, as well as setting up the optional `systemd` user service for persistent background operation.

## Building from Source

To build the CLI, you will need a recent version of the Rust toolchain installed on your system.

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/your-repo/hyde-ipc.git
    cd hyde-ipc
    ```

2.  **Build the CLI**:
    The `hyde-ipc` executable is located in the `cli/` directory of the workspace. To build it in release mode, run:
    ```bash
    cargo build --release -p hyde-ipc
    ```

3.  **Locate the Binary**:
    The compiled binary will be located at `target/release/hyde-ipc`.

4.  **Installation**:
    You can copy this binary to a directory in your system's `PATH`, such as `/usr/local/bin/`:
    ```bash
    sudo cp target/release/hyde-ipc /usr/local/bin/
    ```

## Shell Completions

The build process automatically generates shell completion files. These are placed in the `target/completions/` directory relative to the workspace root.

To install them, copy the appropriate completion file for your shell to its designated location. For example, for Bash:

```bash
sudo cp target/completions/hyde-ipc.bash /usr/share/bash-completion/completions/hyde-ipc
```

## Systemd User Service (`setup` command)

`hyde-ipc` includes a `setup` command to manage a `systemd` user service. This service is essential for running a persistent `hyde-ipc` instance that can handle global event reactions.

**Key Commands**:

*   **`hyde-ipc setup --install`**: Creates and enables the `systemd` user service file (`~/.config/systemd/user/hyde-ipc.service`).
*   **`hyde-ipc setup --uninstall`**: Disables and removes the service file.
*   **`hyde-ipc setup --start`**: Starts the service.
*   **`hyde-ipc setup --kill`**: Stops the service.
*   **`hyde-ipc setup --restart`**: Restarts the service. This is useful after updating the global configuration.
*   **`hyde-ipc setup --check`**: Checks the current status of the service.
*   **`hyde-ipc setup --watch`**: Tails the logs of the service using `journalctl`.

### How It Works

The service runs `hyde-ipc` in a special mode that loads a global configuration file (typically located at `~/.config/hyde-ipc/reactions.toml`) and listens for all specified events.

To configure the service, see the documentation for the **[Configuration](https://github.com/your-repo/hyde-ipc/wiki/5.-Configuration)** and the **`global`** command in the **[Command Reference](https://github.com/your-repo/hyde-ipc/wiki/2.-Command-Reference)**.
