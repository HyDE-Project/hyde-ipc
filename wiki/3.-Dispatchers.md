# 3. Dispatchers

The `dispatch` command is used to send commands directly to the Hyprland compositor. This page lists the available dispatchers and their arguments.

**Note**: This list is based on the help output within the `hyde-ipc` source code and reflects the capabilities of the underlying `hyprland-lib`.

---

### Window Identifiers

Several dispatchers operate on a specific window. Windows can be identified using the following formats:

*   `class:<REGEX>`: Matches a window by its class name (e.g., `class:kitty`, `class:^(Alacritty)$`).
*   `title:<REGEX>`: Matches a window by its title.
*   `pid:<PID>`: Matches a window by its process ID.
*   `address:<ADDR>`: Matches a window by its memory address (e.g., `address:0x5934277460f0`).

---

## Dispatcher List

### Basic Commands
*   `exec <command>`: Executes a shell command.
*   `killactivewindow`: Kills the currently focused window.
*   `exit`: Exits Hyprland gracefully.
*   `forcerendererreload`: Forces the renderer to reload.

### Window Management
*   `togglefloating [window]`: Toggles floating mode for a window. If `[window]` is omitted, it applies to the active window.
*   `togglefullscreen <type>`: Toggles fullscreen mode. Type can be `Real`, `Maximize`, or `NoParam`.
*   `togglefakefullscreen`: Toggles fake fullscreen for the active window.
*   `togglepseudo`: Toggles pseudo-tiling for the active window.
*   `togglepin`: Pins the active window, making it visible on all workspaces.
*   `toggleopaque`: Toggles opacity for the active window.
*   `centerwindow`: Centers the active window on the screen.
*   `bringactivetotop`: Brings the active window to the top of the render stack.

### Focus Control
*   `movefocus <direction>`: Moves focus in a direction. `<direction>` can be `up`, `down`, `left`, or `right`.
*   `focuswindow <window>`: Focuses a specific window using a window identifier.
*   `focusmonitor <identifier>`: Focuses a specific monitor.
*   `focusurgentorlast`: Focuses the most recently marked "urgent" window, or the last focused window.
*   `focuscurrentorlast`: Switches focus between the current and the previously focused window.

### Window Movement & Resizing
*   `movewindow <target>`: Moves the active window. `<target>` can be a direction (`dir:up`, `dir:down`, etc.) or a monitor identifier (`mon:1`, `mon:DP-1`).
*   `resizeactive <params>`: Resizes the active window.
*   `resizewindowpixel <params> <win>`: Resizes a specific window by a pixel amount.
    *   **Resize Params**:
        *   `delta <dx> <dy>`: Resizes by a delta value (e.g., `delta 10 -20`).
        *   `exact <width> <height>`: Resizes to an exact size (e.g., `exact 800 600`).

### Workspace Management
*   `workspace <workspace>`: Switches to a workspace.
*   `movetoworkspace <workspace>`: Moves the active window to a workspace.
*   `movetoworkspacesilent <workspace> [window]`: Moves a window to a workspace without switching focus to it.
*   **Workspace Identifiers**:
    *   A number (e.g., `1`, `2`).
    *   Relative movement (e.g., `right:1`, `left:2`).
    *   Keywords: `previous`, `empty`, `name:<NAME>`.

### Cycling and Swapping
*   `cyclewindow <direction>`: Cycles focus through windows. `<direction>` can be `next` or `previous`.
*   `swapwindow <direction>`: Swaps the active window with another in the specified direction (`up`, `down`, `left`, `right`).

### Cursor Control
*   `movecursortocorner <corner>`: Moves the cursor to a screen corner. `<corner>` can be `topleft`, `topright`, `bottomleft`, `bottomright`.
*   `movecursor <x> <y>`: Moves the cursor to an absolute position.

### Layout-Specific Commands
*   **Dwindle**:
    *   `togglesplit`: Toggles the split direction (horizontal/vertical).
*   **Master**:
    *   `swapwithmaster <param>`: Swaps the active window with the master window.
    *   ... and other master layout commands (`focusmaster`, `addmaster`, etc.).

### Window Grouping
*   `togglegroup`: Toggles the current window's membership in a group.
*   `changegroupactive <direction>`: Switches focus to the next window in the group (`forward`, `back`).
*   `moveintogroup <direction>`: Moves the active window into a group in the specified direction.
*   `moveoutofgroup`: Moves the active window out of its current group.
